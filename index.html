Gauge.js

你的 AI 訂閱額度，一眼掌握。

自架多帳號訂閱額度儀表板，整合 Antigravity、Codex、Claude 與 Grok，定期查詢剩餘額度與重設時間，透過 Web Push 通知額度偏低、恢復與憑證過期。

GitHub 原始碼 安裝與部署 安全政策 完整企劃書

這裡是專案介紹，不是儀表板。GitHub Pages 不執行 Node.js、保存訂閱憑證或提供 API。請自行在本機或 HTTPS 雲端部署，於該服務網址使用儀表板；本頁不要求輸入 PIN 或登入供應商。

四家、多個帳號

從網頁開始 OAuth 登入，不讀取本機 CLI 憑證。依帳號設定監測間隔與提醒門檻。

可安裝的 PWA

離線開啟介面外殼、查看趨勢與重設倒數。推播需要 HTTPS、裝置支援及通知授權。

十主題、三語系

白到黑十款主題，跟隨系統或手動選擇；繁體中文、English、日本語，記住你的偏好。

資料由你管理

Node.js ≥22.13、原生 SQLite 與零執行期第三方套件。雲端必須有 PIN 與 HTTPS origin；資料與備份需妥善保護。

開始使用

取得原始碼後，使用支援版本的 Node.js 執行 npm install、npm run build、npm start，再開啟 http://localhost:8787。Replit 與其他雲端請先依 README 配置 Secrets、HTTPS、持久磁碟和備份。

平台休眠期間不會監測；離線外殼不代表資料是最新。供應商內部端點可能改版，真實登入、刷新與裝置推播必須在你的部署上完成驗證。

驗證狀態

本介紹頁不宣稱測試已通過、服務已部署或手動 Gate 已完成。四家真實帳號、兩輪 token 刷新、Replit 登入、推播交付、24 小時運作、無障礙与備份還原等驗收要求列於企劃書。
